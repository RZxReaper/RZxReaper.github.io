# aronnya-win98

Aronnya Pal's personal site: a Windows 98 style desktop built with React, Vite and React Router.

```bash
npm install
npm run dev
```

`npm run build` writes `dist/`. It also copies `index.html` to `404.html`, which is how GitHub Pages serves the `/invention` route on a direct visit.

Pushing to `main` deploys to GitHub Pages through `.github/workflows/pages.yml`.
